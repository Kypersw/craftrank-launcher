Crash messages now name the real problem on Forge and NeoForge. When mod loading fails, the launcher used to show only the first line ("Failed to start FML", "Mod Loading has failed"); it now shows the reason under it, such as which mod is missing a dependency, which file is not a valid mod, or which mod is made for another Minecraft version. Generic "it failed" lines are no longer shown when a more specific error is in the log.
