Clearer crash reasons. When Minecraft closes with an error, the launcher now names the real cause in more cases: on new versions it reads the game's log properly and says which mods are incompatible and why, it names the mod whose code failed to load (mixin errors), and it says when a mod needs Sodium, Iris, Fabric API or OptiFine. ForgeOptiFine no longer starts with Sodium, Embeddium, Rubidium, Oculus or Iris copied into its mods folder by hand: the launcher lists those files and asks you to remove them, because they always crash the game together with OptiFine.
