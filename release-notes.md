Settings has a new option, "Send anonymous usage statistics" (on by default). With it on, the launcher tells CraftRank when a game starts and ends: the Minecraft version, the loader, the server you join, how long you played, and the kind of PC (Windows version, memory, graphics card brand). Your name, account and files are never sent. This helps us see which versions and servers to test CraftBoost on, and which games fail to start. Turn it off and nothing is sent.
