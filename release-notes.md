Clearer crash reasons for Forge 1.12.2. When Forge stops the game during start-up, the launcher now shows the error that caused it instead of Forge's generic "exit trapped" line, and says so plainly when no other error was printed. It also tells you when a mod needs a Mixin loader (install MixinBooter on Forge 1.12.2) and when the game was started with a Java version it can't run on.
