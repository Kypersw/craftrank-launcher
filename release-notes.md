Minecraft 1.17 with mods no longer crashes on start. Many Fabric and Forge mods for 1.17 are built for Java 17, while 1.17 asked for Java 16, so the game stopped with "The requested compatibility level JAVA_17 could not be set". The launcher now runs every 1.17 version on Java 17, which the game supports fine. When a mod needs a newer Java than its Minecraft version, the launcher now says so in plain words.
